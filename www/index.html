安全与常见问题

服务器存在哪里？用 Cloudflare 吗？

这一版就是纯静态托管在你自己的 Cloudflare Pages 上（keepass.666415.xyz）：服务器上只放网页代码，没有存密码的后端，所以不存在「密码存在哪台服务器」的问题。托管方存的只是网页代码，不是你的密码库；.kdbx 永远在你自己选的位置——本地文件是手动选文件解密，坚果云是直接拉取解密。

解密后密码存在哪里？

只存在浏览器内存里。不写 localStorage、不写 IndexedDB；点锁定、关页面、或超过设定时间无操作，内存里的明文立刻清空。图标也不去网上抓，避免泄露你有哪些账号。

能直接读坚果云里的文件吗？

能，已经加上了。切到解锁页的「坚果云」标签，填文件完整地址（https://dav.jianguoyun.com/dav/…/你的文件.kdbx）、坚果云账号、第三方应用密码（在坚果云客户端的账户信息 → 安全选项 → 第三方应用管理里生成，网页版没有这个入口，不是登录密码），再填密码库主密码，就能直接拉取并在本地解密。改完在「设置 → 坚果云同步」里点「保存回坚果云」直接写回，不用再下载、手动替换文件。连接走的是 Cloudflare 上 keepass-proxy 这个 Worker 的自定义域名（keepass-proxy.666415.xyz），跨域问题由代理解决，不用你填什么；连不上会明确报连接失败，也可以改回本地文件方式——坚果云客户端先把文件同步到本地，再用「本地文件」打开，效果一样且不受跨域影响。

需要联网吗？

第一次打开页面需要联网加载代码；页面打开后，解锁、搜索、复制、改密码都不用联网。关掉页面再打开，需要重新联网加载一次。用坚果云打开和保存时当然需要联网拉取 / 写回文件。

iPhone 上怎么用得顺手？

用 Safari 打开 → 分享 →「添加到主屏幕」，之后像 App 一样点开。改完之后，坚果云打开的库点首页的「保存回坚果云」就行；本地打开的库才需要导出新 .kdbx 再替换旧文件。需要系统自动填充时，同一个文件用 Strongbox / KeePassium 打开即可，两边混用没问题。

改了为什么一定要导出？

不一定。电脑版 Edge / Chrome 上，用「本地文件」点选打开 .kdbx，改完点「保存」就能写回同一个文件，不用导出替换；坚果云打开的库点「保存回坚果云」就行。手机 Safari 等不支持的浏览器、拖放打开的文件，仍需导出新文件再替换旧文件；不导出就关页面，修改会丢，顶部也会有未保存圆点提醒你。

主密码忘了怎么办？

没有任何办法找回——这正是 KeePass 的设计：没有主密码，谁都解不开。建议主密码用一句你记得住的话，并把数据库多备份一份。

导出绑定清单

把密码库里有手机号或邮箱的账号导成 Excel 清单，只含标题名称、账号、手机号、邮箱、备注五列，方便对一遍哪些号绑了哪些账号。没密码的账号（谷歌登录、微信小程序）先加一张卡片、密码留空，一起导出来。

导出的是真 .xlsx 文件，Excel 能直接打开；手机号、邮箱按文本存，不会变成科学计数法。

面容 ID 解锁

只在 iPhone 原生 App 里可用。开启后，主密码存在 iPhone 的钥匙串（Keychain）里，下次打开这个文件时点一下面容 ID 就能解锁，不用再输主密码。网页版没有钥匙串，不能用面容 ID。

面容 ID 解锁当前文件未开启

开启后只对当前这个文件有效；换了文件要重新开。用了密钥文件的库不能用面容 ID。关闭会立刻删掉钥匙串里存的主密码。

账号模板

新建账号时先选模板，表单按模板生成字段。只有标题是每个模板自动带的（必填），不可删除；账号、密码需要时自己加。模板存在密码库文件里，跟着 .kdbx 走，换浏览器、换设备都有。

常用手机号 / 邮箱

存在密码库文件里，跟着 .kdbx 走。填账号时，手机号、邮箱、账号字段都可以从这里选；换号后批量修改也从这里选新值。

字段兼容性

新改的条目里，手机号、邮箱这些普通字段存的是明文，其他 KeePass 软件打开能直接看到；只有密码类字段存成掩码。老条目还是以前的存法，在别的软件里显示成 •••••，点下面这个按钮可以一次全转过来。

只改浏览器内存里的数据，密码类字段不受影响；转完记得点「保存」（或「保存回坚果云」），才会写进文件。

别的 KeePass 软件用模板建账号时，会在条目里写一个 _etm_template_uuid 字段，记着它是用哪个模板建的。这个字段不含密码、不影响登录，我们网页版也不用它；删了之后原来那个软件就认不出这些账号是用哪个模板建的了。只清正常分组里的条目，回收站里的不管；只改浏览器内存里的数据，删完记得点「保存」（或「保存回坚果云」），才会写进文件。

修改主密码

改完主密码后记得点「保存」（或「保存回坚果云」），新密码只在保存之后才生效。改密码不会动密钥文件（如果这个库用了密钥文件，改完还是要密钥文件才能打开）。
